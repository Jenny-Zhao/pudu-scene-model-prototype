# 清洁机器人 · 场景模型产品原型

围绕「场景模型」能力的两端交互原型：

| 原型 | 入口 | 内容 |
|---|---|---|
| 地图场景模型 | [map/index.html](map/index.html) | 地图列表 / 建图信息 / 建图方式三页：建图时按场景自动匹配模型，可手动切换，含「什么是场景模型」说明、场景与默认模型映射表、修改路径图示 |
| 本体 AI 清洁策略 | [ai/index.html](ai/index.html) | 真机设置页风格：湿垃圾 / 干垃圾 / 障碍物分组的能力清单，每项可配置「清扫 / 避让 / 不处理」，能力清单随场景模型下发 |
